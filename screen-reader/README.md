# Screen Reader & Commander

Güncel proje açıklaması ve kurulum notları için [ana README dosyasına](../README.md) bakın.

Mevcut uygulama; Windows üzerinde sesli komutları işlemek için faster-whisper, komut yorumlamak için yerel bir GGUF dil modeli ve ekran üzerindeki öğeleri bulmak için Florence-2 kullanır. Playwright/CDP, pywinauto ve PyAutoGUI etkileşim katmanlarını oluşturur.

Proje geliştirme aşamasındaki bir prototiptir. Önceki YOLO, EasyOCR ve SpeechRecognition açıklamaları mevcut kodu yansıtmıyordu; güncel mimari ana README'de belgelenmiştir.
